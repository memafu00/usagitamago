# 卯たまごのにっき 🐰🥚

> ～インターネットの世界から～

歌声合成ソフトUTAUの音源キャラクター「卯たまご」の公式サイトへようこそ。
管理者の めまふ です。お越しいただきありがとうございます。

卯たまごは、春眠でネットの世界に迷い込んだ元・人間の子。
記憶のほとんどを忘れてしまっていて、ネットの情報で日々それを上書きしながら、うさぎのぬいぐるみになったり人間の姿に戻ったりしています。
このサイトでは、そんな卯たまごの日記・物語・UTAU音源を のんびり公開しています。どうぞゆっくり楽しんでいってください。

ところどころに、ちょっとした仕掛けを隠してあります。気づいてもらえたら うれしいです。
